## Objetivo de la Carpeta

La carpeta `Schemas` tiene como objetivo almacenar y organizar los esquemas de las bases de datos NoSQL, definiendo la estructura de colecciones, validaciones y modelos necesarios para la correcta gestión de la información del sistema.
