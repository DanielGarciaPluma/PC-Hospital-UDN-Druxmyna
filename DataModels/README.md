# DataModels

## Objetivo de la Carpeta

La carpeta `DataModels` tiene como objetivo organizar y almacenar los modelos de análisis de datos y aprendizaje automático utilizados dentro del proyecto, permitiendo administrar algoritmos supervisados y no supervisados para el procesamiento, clasificación y análisis de información.

---

## Descripción de Subcarpetas

### Supervised_LMs/
Contiene modelos supervisados entrenados con datos etiquetados para realizar predicciones, clasificaciones y análisis específicos.

### Unsupervised_LMs/
Incluye modelos no supervisados enfocados en descubrir patrones, agrupaciones y relaciones dentro de los datos sin etiquetas previas.
