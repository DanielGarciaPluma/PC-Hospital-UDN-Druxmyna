## Objetivo de la Carpeta

La carpeta `WebApp` tiene como objetivo almacenar y organizar todos los recursos, configuraciones y componentes necesarios para el desarrollo de la aplicación web del proyecto, integrando la estructura de construcción, documentación, código fuente y manuales asociados al sistema.
