## Objetivo de la Carpeta

La carpeta `source` tiene como objetivo almacenar y organizar el código fuente principal de la aplicación WebApp, incluyendo los componentes de backend y frontend necesarios para la lógica del sistema, procesamiento de datos e interacción con el usuario.

---

## Árbol de la Carpeta

```text
source/
├── backend/
│   └── README.md
├── frontend/
│   └── README.md
└── README.md
```
