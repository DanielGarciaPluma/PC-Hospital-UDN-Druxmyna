## Objetivo de la Carpeta

La carpeta `frontend` tiene como objetivo almacenar y organizar los componentes visuales e interfaces de usuario de la aplicación WebApp, permitiendo la interacción con el sistema mediante vistas, pantallas y recursos orientados a la experiencia del usuario.
