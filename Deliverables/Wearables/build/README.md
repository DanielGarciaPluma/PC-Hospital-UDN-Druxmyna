## Objetivo de la Carpeta

La carpeta `build` tiene como objetivo almacenar y organizar los archivos generados durante el proceso de compilación del módulo Wearables, incluyendo artefactos, configuraciones temporales y recursos necesarios para su ejecución.

```text
└── README.md
```
