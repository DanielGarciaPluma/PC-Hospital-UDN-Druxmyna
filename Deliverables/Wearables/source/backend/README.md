## Objetivo de la Carpeta

La carpeta `backend` tiene como objetivo almacenar y organizar la lógica del lado del servidor del módulo Wearables, incluyendo procesamiento de datos, gestión de servicios, conexión con APIs y manejo de la comunicación interna del sistema.
