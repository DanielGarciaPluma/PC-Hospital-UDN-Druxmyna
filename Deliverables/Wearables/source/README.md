## Objetivo de la Carpeta

La carpeta `source` tiene como objetivo almacenar y organizar el código fuente principal del módulo Wearables, incluyendo los componentes de backend y frontend necesarios para el funcionamiento, procesamiento e interacción del sistema.

---

## Árbol de la Carpeta

```text
💻 source
│
├── 🛠️ backend
│   └── README.md
│
├── 🎨 frontend
│   └── README.md
│
└── README.md
```
