## Objetivo de la Carpeta

La carpeta `API` tiene como objetivo almacenar y organizar los componentes encargados de la comunicación entre los modelos de aprendizaje automático y las demás partes del sistema, permitiendo la gestión de solicitudes, respuestas y la integración de servicios para el procesamiento de datos.
