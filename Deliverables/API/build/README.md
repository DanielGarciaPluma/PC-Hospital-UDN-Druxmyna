## Objetivo de la Carpeta

La carpeta `Build` tiene como objetivo almacenar y organizar los archivos generados durante el proceso de compilación y construcción del proyecto, incluyendo versiones ejecutables, artefactos temporales y recursos necesarios para la ejecución del sistema.
