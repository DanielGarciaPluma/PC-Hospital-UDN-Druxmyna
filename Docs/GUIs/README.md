# GUIs

## Objetivo de la Carpeta

La carpeta `GUIs` tiene como objetivo almacenar y organizar los diseños de interfaces gráficas del sistema, incluyendo prototipos, estructuras visuales y referencias de diseño para las diferentes plataformas del proyecto.

---

## Árbol de la Carpeta

```text
GUIs/
├── WearableApp/
├── WebApp/
└── README.md
```

---

## Estructura de Subcarpetas

### `WearableApp/`
Contiene los diseños gráficos y prototipos de la aplicación para dispositivos wearables.

### `WebApp/`
Almacena las interfaces gráficas y prototipos correspondientes a la aplicación web.
