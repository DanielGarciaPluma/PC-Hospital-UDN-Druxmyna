# 🔐 Reglas de Usuario

---

## 👨‍💼 Administrador del Sistema

- Puede registrar, editar, consultar y eliminar información del sistema  
- Tiene acceso completo a todos los módulos  
- Puede asignar departamentos y roles al personal  
- Puede gestionar horarios, incapacidades y reclutamiento  
- Puede visualizar reportes generales del sistema  

---

## 👩‍⚕️ Administrador de Recursos Humanos

- Puede registrar y actualizar información del personal  
- Puede gestionar reclutamiento y contratación  
- Puede registrar incapacidades y horarios  
- Puede consultar información relacionada con departamentos y personal médico  
- No puede eliminar configuraciones críticas del sistema  

---

## 👨‍⚕️ Supervisor

- Puede consultar horarios y asignaciones del personal  
- Puede visualizar información del departamento asignado  
- Puede validar asistencia y jornadas laborales  
- No puede eliminar registros del sistema  

---

## 👤 Usuario Consultor

- Solo puede consultar información autorizada  
- No puede registrar ni modificar datos  
- Tiene acceso limitado a reportes y consultas básicas  

---

# 🔒 Restricciones de Usuario

- Todo usuario debe iniciar sesión para acceder al sistema  
- Los permisos dependen del rol asignado  
- Ningún usuario puede modificar información sin autorización  
- El sistema debe registrar la fecha y usuario de cada modificación  
- Los usuarios inactivos no podrán acceder al sistema  
- Las contraseñas deben almacenarse cifradas  
- Toda operación crítica debe quedar registrada en bitácoras del sistema
